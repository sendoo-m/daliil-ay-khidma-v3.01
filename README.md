# دليل أي خدمة — v3

منصة عربية لاكتشاف المحلات ومقدمي الخدمات والمنتجات والعروض. مستودع واحد يضم الخادم وتطبيقين.

| | الرابط |
|---|---|
| تطبيق المستخدم | `https://sendoo-m.github.io/daliil-ay-khidma-v3.01/` |
| لوحة الإدارة | `https://sendoo-m.github.io/daliil-ay-khidma-v3.01/admin/` |

الاثنان يُبنيان من نفس المستودع عبر `.github/workflows/pages.yml` عند كل دفعة إلى `main`.

## البنية

```
backend/                  Django 5.2 + DRF
  apps/administration/    الأدوار والصلاحيات وسجل العمليات
  apps/api/               عقود الـAPI (v2)
  apps/directory/         الأنشطة والتصنيفات والمواقع
  ...

mobile/
  packages/dalil_core/    مشترك: الشبكة، الرموز، الأخطاء، قيم التصميم
  apps/user/              تطبيق المستخدم — Android · iOS · Web
  apps/admin/             لوحة الإدارة — Web · Android
```

`dalil_core` هو ما يمنع تكرار الكود: عميل HTTP واحد، ومنطق تجديد رمز واحد، ورسائل خطأ عربية واحدة. إصلاح فيه يصل للتطبيقين معًا.

---

## الفرق عن v2

**نظام صلاحيات حقيقي.** v2 كانت تفحص `is_staff` فقط — موظف الدعم كان يملك نفس صلاحيات المدير العام. v3 فيها أدوار قابلة للإنشاء من التطبيق، وصلاحية منفصلة لكل عملية.

**نطاق جغرافي.** مراجع في أسيوط يرى ويوثّق أنشطة أسيوط فقط. يُطبَّق على مستوى الـqueryset فلا يمكن نسيانه في شاشة جديدة.

**سجل عمليات لا يُمحى.** كل تعديل مسجَّل بفارقه: من، ماذا، متى، ومن أي عنوان.

**أخطاء مُصلَحة من v2:** الفرز بالمشاهدات كان يرمي 500، والـserializers كانت للقراءة فقط فتعذّر إنشاء نشاط من التطبيق، و`analytics` كانت 48 استعلامًا في الطلب الواحد.

التفاصيل في [`docs/MIGRATION_FROM_V2.md`](docs/MIGRATION_FROM_V2.md).

## التشغيل المحلي

### الخادم

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_roles          # ينشئ الأدوار الستة
python manage.py createsuperuser
python manage.py runserver
```

### لوحة الإدارة

```bash
cd mobile/apps/admin
flutter pub get
flutter run -d chrome --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

### تطبيق المستخدم

```bash
cd mobile/apps/user
flutter pub get
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

## الأدوار الافتراضية

| الدور | ما يفعله |
|---|---|
| مدير عام | كل شيء، بما فيه إدارة الأدوار |
| مدير تشغيل | المحتوى والأنشطة والفريق، بلا صلاحيات نظام |
| مراجع أنشطة | يراجع الأنشطة ويوثقها — يُقيَّد بنطاق جغرافي |
| مشرف محتوى | التقييمات والمحتوى المُبلَّغ عنه |
| دعم فني | اطلاع لمساعدة المستخدمين |
| محلل بيانات | التقارير فقط |

الأدوار بيانات لا كود. المدير ينشئ أدوارًا جديدة من التطبيق بلا نشر.
